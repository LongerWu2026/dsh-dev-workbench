# 待办消息发出时间列

任务列表新增独立“消息发出时间”列，显示原消息的北京时间（精确到秒）。点击列头切换最新/最早在前，筛选区也可选择消息时间排序或恢复默认排序。可指定起始、截止日期，包含北京时间截止日全天；与搜索、状态、项目、事项类型等筛选组合使用，看板共用相同筛选。

时间只取原任务关联来源的 `locator.sentAt`，支持主来源缺失时使用已有来源引用。采集时间、待办创建时间、会议开始时间不能替代原消息时间；后续关联消息不覆盖原任务时间。手动待办、日历来源及缺少/非法原消息时间的待办显示“—”，按消息时间升降序时均置后，限定日期后不参与结果。

筛选、排序作用于全量匹配记录后再分页；修改条件回到第一页，重置恢复默认条件。从其他入口定位指定任务时会清理日期和排序以保证任务可见。操作只影响当前页面，不更改业务记录。列表将原来标题下重复的时间移入独立列，首页/看板/来源详情继续保留原消息时间。窄屏列可横向滚动，日期控件换行。
