# 助手指令识别与逐条反馈

每条助手提交保存原话、识别来源、实际指令、结果或失败原因。规则先展示识别指令，再返回原业务服务回执；AI 从原生请求与工具事件关联实际调用，工具无文本、模型空返回、提交失败、知识未命中都给出明确回应。后台任务进度与最终状态回填发起它的那条消息，待确认操作不会因其他后台作业完成而显示整轮完成。

- 请求身份在提交前持久化，相同请求重试不重复执行。原生消息以 `source.rpcId` 关联，工具以 callId 关联，不根据相似文字猜测。
- 旧 AI 互动记录只读还原实际命令和结果，不伪造已执行操作。历史分页与当前范围隔离；后台规则历史缺少来源时不补造识别信息。
- “改用 AI 识别”创建关联原消息的新识别回复，只提供理解与建议。宿主按真实活动请求拦截所有工具，不能重放原动作；没有拦截能力则拒绝启动。继续执行仍需用户后续明确指令，原确认机制保留。
- 后台每批最多 50 条消息可展开逐条识别建议，明确无需处理、缺失结果、重复/错误来源和无效格式；这些是 AI 建议，实际登记仍取业务状态。资讯展示四段实际摘要，缺失段落明确说明。
- 工具出口清除不属于 JSON 的可选 undefined 值，标准助手工具的文本与结构化回执同源，修复实机旧历史中的 `value is not lossless JSON`。
