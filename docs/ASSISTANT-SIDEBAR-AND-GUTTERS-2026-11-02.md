# 助手会话列表折叠与左右边距

会话列表的折叠按钮已从系统能力工具栏移至列表自身顶部右侧，与“会话”和新建按钮同一行。桌面折叠后保留40px窄栏，提供展开和新建入口。窄屏不占用窄栏宽度，入口位于聊天标题左侧，列表作为带遮罩的抽屉展开。

## 布局与状态

- 按助手面板实际宽度适配，宽度不超过640px时使用抽屉；大窗口里的窄面板同样生效。进入窄屏默认关闭列表，回到桌面恢复本次打开期间的桌面折叠选择。
- 抽屉支持遮罩关闭、Escape、Tab焦点循环和关闭后焦点返回。抽屉打开时底层聊天区域inert，防止误操作；正在处理时即使新建按钮不可用，关闭按钮仍可聚焦。
- 折叠与尺寸变化只更新布局状态，聊天区域保持挂载，不改变会话ID、原生会话选择、文字草稿、图片/文件附件或正在返回的回答，不触发新建会话、上传或模型调用。
- 列表搜索内容继续由助手持有，折叠后不会清除。窄屏选择当前会话也会关闭抽屉，返回原输入位置。
- 助手外框与今日简报共用24px桌面左右留白和12px窄屏留白、1500px内容上限；超宽屏继续居中对齐。
- 聊天消息与输入框左右对齐；窄屏附件预览限制高度并内部滚动，短窗口继续保留输入和发送操作。
- 侧栏逻辑与样式拆入 `src/client/components/AssistantSidebar.tsx`，不重写现有会话、附件和Host服务。

## 验证

- `pnpm build`、`pnpm check`、`pnpm test`通过；完整React界面测试573项。
- `pnpm test:layout`：205个通用布局场景通过。
- `node plugin-tests/layout/assistant-sidebar.mjs`：42个新增场景通过，覆盖360/560/640/800/1280/1800宽度、360短高度、明暗主题，以及1280窗口中的600px面板。逐像素比较助手外框与简报内容左右边界，误差为0px；全部场景保持同一输入DOM、同一会话、原草稿及两个未发送附件。
- `node plugin-tests/layout/assistant-hub.mjs`：88个助手布局场景通过。
- `node plugin-tests/layout/assistant-materials-identity.mjs`：32个身份/附件场景通过。
- `node plugin-tests/layout/assistant-latest.mjs`：16个最新消息与历史阅读定位场景通过。
- 原版Harness实机确认按钮位于列表标题行、折叠后出现窄栏；在既有会话输入临时草稿，折叠与展开后仍保留同一会话和文字。测试文字已清空，未点击发送，未新建会话、选择真实附件或手动触发业务操作。

无界面浏览器验证只加载合成数据并阻止联网；实际附件保留由同一客户端产物的React与真实浏览器文件选择回归验证，没有把测试文件上传给模型厂商。共享工作区其他未提交改动保留。
