# 智能工作台统一实施与交付方案

更新：2026-10-28，0.2.0 工作树。当前架构见 [架构说明](PROJECT-ARCHITECTURE-AND-FEATURES.md)，本轮证据见 [实施记录](IMPLEMENTATION-STATUS-0.2.0.md)，任务状态唯一入口为 [待办13–25](TODO-AI-AUTOMATION.md)。

## 1 当前已实施的分层

页面与聊天工具共用Host业务服务。确定性采集→来源与游标提交→持久分析队列→独立后台会话→结构/证据/时间/关联校验→Reply与Task分别更新。网络和模型等待位于写锁之外，提交在副本上完成，落盘成功后发布缓存。

消息以组织/账号、会话、消息定位，项目参与上下文范围。本人和普通消息作为上下文，不能直接生成本人新交办。长身份先构造稳定摘要，避免持久化字段截断导致去重错误。超限、失败和会话发现保留继续位置，补采后按时间理解。

耗时操作返回jobId，由持久化作业和分析队列反映进度；一轮采集后分析一次，再进行资讯摘要。关闭主开关不启动新的模型条目；退出/休眠暂停，恢复后继续到期及待执行工作。

## 2 工程与界面

源码已迁移为TS模块、共享契约和TSX组件；构建保持DSH加载格式，严格检查和产物一致性检查进入本地命令。动态宿主边界与部分旧页面仍有显式any，后续按已验证契约逐步缩小。

内部左栏改顶部目录，常用办公模块位于首层，原工具能力放在更多。主内容优先待回复和待办，资讯为辅助；统计与空态按内容高度展示。窗口顶部使用宿主安全区，容器宽度决定单列、双列和侧区模式。

任务编辑与助手共享侧区，草稿独立于快照，切换模块后可继续编辑。完整待回复和资讯页不依赖首页截取；识别队列支持分页、确认、重试和取消。详见 [界面设计](UI-REDESIGN-AND-REFERENCES.md)。

## 3 资讯与迁移

资讯：关注主题与时间范围→宿主搜索/RSS→原文→摘要→主题/项目匹配→卡片。未知日期明确标注，HTTP/模型失败单条保留，缺段可补齐，已有摘要优先保留。排序目前是可解释的关键词匹配，不是模型语义推荐。

迁移：完整业务快照→只读预检→数量/冲突/目录映射→成功备份→重新校验→原子提交→独立进程重载。后台模型仍运行时拒绝实际导入。凭据和原生会话单独管理；旧字段升级保留ID和业务关联。
