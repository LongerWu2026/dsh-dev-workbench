# 多 AI 对话：增量展示与 Markdown 格式

## 改动

- 官网观察间隔从 1500ms 调整为 750ms。相同正文不重复提交状态更新，完成判断仍依赖本轮官网结束证据和稳定复核。
- 新回答的增量在前端按 Unicode 字符逐步展示；长块自动加速追赶。历史、切换厂商、正文修订、隐藏页面和减少动态效果时直接展示对应内容。
- 展示动画独立于采集与持久化，复制、保存知识、导出继续使用完整已采集内容，不会保存播放中的半截文字。
- 使用 markdown-it 15.0.3 解析，React 白名单构造元素，支持标题、粗斜体、删除线、引用、嵌套列表、起始编号、表格、链接、代码语言及未闭合代码围栏。
- 网页 DOM 采集保留对应语义结构，表格转换为有效 Markdown。代码中的反引号不会提前关闭围栏。
- 表格和长代码在内容区域内滚动，跟随工作台深浅色主题。读取旧内容时持续输出保持阅读位置，切换厂商保留草稿。

## 范围

这是官网 DOM 增量采集加本地打字展示，没有改用模型 API。新内容到达速度受官网更新和内嵌页面调度影响；没有读取官网私有网络协议。

回答使用工作台统一的 Markdown 样式，保留常见内容结构。官网专属交互卡片、数学公式排版和图表不作等像素复制，可以在“登录 / 查看原对话”中查看。不会向工作台注入官网 HTML、样式、脚本或自动加载回答中的远端图片。

以前已经以纯文本保存、丢失语义标记的历史内容无法凭空复原；新采集内容及本来包含 Markdown 的历史使用新渲染器。需要恢复旧内容时可使用现有“采集本轮回答”入口，不自动重发问题。
