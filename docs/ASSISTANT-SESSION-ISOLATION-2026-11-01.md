# 待办 AI 协助与研发会话隔离

截图中的页面是工作台 AI 助手，顶部仍是今日简报；助手会话选择框误选了研发任务，正文因此显示 read/bash 工具记录。根因是前端没有有效 assistantSessionId 时回退到原生会话列表第一项，最近活动的研发会话可能被自动采用。

修正后，首次打开只恢复 Host 指定的办公助手会话，无默认绑定时读取默认 transcript，让 Host 恢复或新建办公会话，不再自动挑选最近的原生会话。列表为空时也会初始化正确会话。当前待办仍以可见、可移除的上下文附在输入区，点击图标不自动发送。
