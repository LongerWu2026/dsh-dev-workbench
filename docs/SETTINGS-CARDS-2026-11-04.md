# 连接与设置卡片布局

设置页由两个独立长列改为同一个自适应卡片网格。自动化与数据管理占整行，自动化选项在宽屏分两列，运行记录与归档另行排列。

数据管理抽成独立 `DataManagement` 组件：左侧导出与备份，右侧迁移导入，下方示例与重置；窄容器自动改为单列。卡片使用宿主主题色、统一边框、标题、图标和按钮间距，备份列表独立滚动。文件选择控件、导入方式与操作按钮统一排版，减少窄列堆叠。

迁移草稿、预检结果及目录映射随组件保留。合并/替换规则、只预检再执行的流程、恢复备份与重置的确认继续保留。
