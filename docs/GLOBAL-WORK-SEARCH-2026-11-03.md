# 工作搜索入口收敛

## 行为

- 工作搜索从主导航和“更多”移除，内部搜索结果路由保留。
- 顶部搜索图标与 Cmd/Ctrl+K 打开同一个快速搜索弹窗。支持类型筛选、键盘选择、关闭后焦点恢复，以及忽略已过期请求。
- 快速搜索只查询已保存的待办、知识、资讯与消息。新增 `scope=local` 在外部服务、本地文件扫描、企业 CLI、GitHub 和公网检索之前返回，输入不会发给外部检索服务。
- 点击待办直接定位原事项，其他结果可查看完整已保存正文。查看全部时保留关键词、类型和本地范围，进入完整结果页；旧的工作/互联网搜索范围仍兼容。
- AI 继续处理替换上次上下文；待办、知识、资讯恢复对应事项会话，消息优先恢复关联待回复或待办，否则进入消息识别固定会话。外部结果使用带来源的检索摘要，不伪造成本地记录 ID。
- 助手联网搜索只预填可编辑指令，发送前不调用模型或搜索。AI 的 `workbench_search` 工具支持明确选择 local/work/web，共用同一后端搜索服务。
- 查询、预览和进入助手均不自动修改业务状态，不自动新建或发送模型会话。

## 验证

- `pnpm build`、`pnpm check` 通过；272 个模块无循环引用或跨层依赖问题。
- 新增 `tests/search-local.mjs` 验证仅本地查询即使带联网参数也不触碰外部服务；无命中返回真实空结果。
- 新增 12 项入口与交接测试，验证快捷键、筛选、结果定位、完整页交接、旧上下文替换、原会话恢复、过期响应、错误和联网指令预填。
- `pnpm test` 全量通过，包括后端脚本及 47 个界面文件、708 项界面测试。日志：`/tmp/global-search-full.log`。
- 最终构建下的 `node plugin-tests/layout/global-search.mjs` 共 18 组通过，覆盖 360/800/1440 宽度、480/900 高度、深浅色、快速弹窗和完整结果页。底部主要操作可见，页面不横向溢出，浏览器无异常。报告与合成截图：`/tmp/workbench-global-search/`。

本轮未重载正在使用的真实客户端，没有发送真实消息或修改真实事项。客户端需加载新版插件后才能显示新入口。
