# 任务中心排版与行点击

- 列表使用固定列布局，长链接和长描述无法再撑大任务列。常规宽度保留表格，内容宽度不超过 1100px 时将同一行的 8 项信息排成多行，600px 以下使用两列布局，状态、完成、时间和操作不再被挤出窗口。
- 标题、来源标记、描述预览与发件人信息形成稳定层次。已有 AI 标记时省略同义的 AI 识别标签；预览按空间截断，展开来源区域可读取完整任务说明。持久化内容和原始来源不改写。
- 筛选区保留搜索、排序、状态标签和高级条件；结果数量与状态标签同排，仅筛选生效时显示结果数量及重置入口。
- 行内空白、描述和来源信息均可点击打开当前待办编辑；按钮、链接、状态选择、完成操作和来源展开独立处理。聚焦行时支持 Enter / 空格打开编辑，选择行内文本不会触发编辑。
