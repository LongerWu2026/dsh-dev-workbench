# 私聊答复后的收尾消息不再遮蔽已回复状态

## 问题与修复

私聊连续两条提问按原消息分别建档。本人答复后，对方发送「好的」等收尾内容时，旧逻辑只检查最新消息发送人，导致已答复的原记录残留为待回复。增量同步仅提供最后一句快照时，也会遗漏中间的本人答复。

现在对每条既有待回复核对其后的有效本人消息：同一账号、同一已确认私聊、真实本人发送、时间严格晚于原问题，且排除工作台忙碌自动回复。本人答复可结清此前同轮的多个问题；答复后对方新提出的问题仍保留待回复，不因「同一个人」直接合并或删除原始证据。

仅有会话末句快照时，从原消息 ID 向后补查，每条最多两页、全轮最多12次额外请求，并保留补查游标及限流退避。群聊仍需本人明确引用原消息，不能用无关发言结清群消息。

保留原有账号隔离、人工并发修改、发送中保护、草稿、归档及任务状态保护。原回复记录只更新阶段、真实答复时间及答复消息证据，不删除记录。
