# 多 AI 聚合聊天界面（2026-10-30）

## 行为

- 左侧搜索、选择历史会话及新建对话，右侧按时间显示提问与多厂商回答。厂商筛选位于上方，发送范围和输入框位于底部。窄屏可展开会话历史。
- 回答接入既有官网增量采集：约每 1.5 秒观察一次官网回答，持续更新同一张回答卡片。不是模型 API 的逐 token SSE；受官网页面结构、登录、验证码及弹窗影响。
- 处于底部时跟随新回答；上翻阅读时保持位置。支持加载更早轮次、Markdown 正文、附件、批量问题、原对话和手动回答编辑。
- 普通问题 Enter 发送，Shift+Enter 换行；中文输入法选词不触发发送。批量模式使用 Ctrl/⌘+Enter。
- 浏览历史不调用新提问或执行认领，不自动重发旧问题。不改动历史存储结构或浏览器持久化分区。

## 已记录的历史登录提示问题

用户反馈：应用首次打开时历史卡片写着“需要登录”，打开官网却已经登录。历史 `needs_login` 是上次采集状态，不能当作当前账号状态。

目前通过展示层区分：尚未检查官网时显示“待继续采集”；检查识别到登录后显示“官网已登录，可继续采集本轮回答”；当前官网明确要求登录时才提示登录。保存的原始历史状态不重写。这个问题不阻碍聊天界面，也不会触发自动补发。
