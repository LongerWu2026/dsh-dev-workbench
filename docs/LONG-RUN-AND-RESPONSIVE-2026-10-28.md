### 实际进程挂起恢复

`pnpm test:suspend` 使用独立子进程和独立DSH_HOME，在模型等待已经开始后发送SIGSTOP，95秒后SIGCONT。模型为合成响应，不连接企业数据或真实提供商。验证5条在途消息不烧重试、清理租约、同一作业回排、继续复用原会话，重试后完成。它是真实操作系统进程暂停，**不是系统休眠**。

### 隔离浏览器布局

`pnpm test:layout` 在独立无头Chrome中加载实际 `client.js`、React及合成数据，所有网络请求被阻断，不连接或遥控日常桌面。覆盖十页、1280/800/560/360像素宽度、浅色/深色、150%/200%页面缩放模拟、任务编辑、8个上下文及320像素高度输入可达。检查几何溢出和控件裁切，并实际滚动后点击任务编辑；不是只检查DOM存在。

缩放使用测试文档的CSS zoom，不能等同macOS辅助字体、所有显示器DPI或原生宿主缩放。系统字体完整矩阵仍保留边界。
