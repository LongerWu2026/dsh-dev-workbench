# 工具箱独立工作区

工具选择入口移至页面顶部：鼠标进入时展开搜索和分类，选择后收起并将焦点返回入口。可点击展开，键盘 Tab 进入、Escape 关闭；搜索框获得焦点时允许继续输入。工具面板占据整行，切换保留各工具输入。

数据连接采用连接与对象侧栏、查询与结果主区。连接配置移入主题弹窗；默认选中第一个已保存连接，显式新建保留草稿。对象列表可搜索，勾选后可读取结构，生成带标识符转义的查询模板，再手动执行。支持 Ctrl/Command+Enter；变更脚本仍仅预览。生成模板不发送查询请求。字段以表格展示，MySQL DDL、ES mapping 与 Redis 原始信息按已有结构保留。

接口与 MCP 工具采用请求/响应两栏，窄屏纵向排列。JSON、编码转换、YAML、CSV、SQL 格式化、Markdown、类型生成采用输入/输出对照；Diff 保留双文本对照；日志保留输入和筛选结果；正则、Cron、时间戳、JWT 保留各自参数与解析结果；UUID 保留批量选项与输出；HTTP 状态码和 Shell 速查保留检索列表；番茄钟保持独立计时与切换后的状态。

验证使用合成数据，阻断浏览器网络请求，不访问真实数据库。完整测试、类型/架构/构建一致性检查通过；前端 29 个文件、405 项测试通过。`plugin-tests/layout/tool-workspace.mjs` 检查 22 个工具在三种宽度及明暗主题下的 132 个场景，并验证菜单交互和数据库生成/手动执行流程。截图及报告位于 `/tmp/workbench-tool-workspace`。数据库专项另有 24 个布局场景通过。
