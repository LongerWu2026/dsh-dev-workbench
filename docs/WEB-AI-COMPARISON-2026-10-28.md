日期：2026-10-28（Asia/Shanghai）。目标范围只有 Kimi、国内智谱清言、豆包、腾讯元宝、千问，以及可选 ChatGPT。

2026-10-29更新：已关闭外部浏览器入口，跨重启登录主路径改为宿主受控持久化分区；客户端接线已准备，宿主扩展及账号恢复尚未验收，见[当前登录保留方案](WEB-AI-LOGIN-PERSISTENCE-2026-10-29.md)。下文的备用Chrome测试为旧实现证据，不代表当前可从工作台启动。

本日后续适配已改为直接提问、首次自动建档，官网默认收起。逐站最新状态与阻塞见[适配复验记录](WEB-AI-ADAPTATION-2026-10-28.md)。未登录账号和锁屏期间不能核销真实发送及回答提取。

## 当前选择

工作台新增独立的「更多 → 网页 AI 对比」。默认使用 Harness 官方 Browser lease 在插件自己的容器内承载官网，不复用原生模型助手，也不创建 Harness 模型会话。正常使用不打开独立浏览器窗口。

当前版本不提供另开Chrome入口，旧Remote方法也拒绝该操作。旧实现曾用专用资料目录验证浏览器标记保留；不连接日常Chrome，不导入其Cookie、密码或资料，工作台不提供导出登录凭证的Remote接口。

旧Chrome资料不会自动带回Harness内嵌页面。内嵌guest的存储由当前宿主决定，默认跨进程不保留，当前不能宣称五家国内网站或ChatGPT都已实现一次登录跨重启恢复。

## 可用行为

- 每个对比主题保存每家官网的会话链接；官网的页面导航会更新链接。仅保留允许的会话ID参数及有限的 hash 路由，不保存登录回调或任意查询参数。
- 同一主题的后续问题复用该站的当前页面；切换厂商、官网/对比视图及工作台业务页不会重新提问。
- 首次直接输入问题即可提交，不需要先创建「对比主题」；后续从「历史问答」选择既有记录继续追问。主界面默认呈现回答，官网收进「登录 / 查看原对话」。
- 每批1–5个问题，用单独一行 `---` 分隔；最多两家厂商并行，同一家依次处理。一条需要人工操作时，该厂商的后续问题保留为未发送，其他厂商继续。
- 默认只发送统一输入框中的文字，不自动携带工作台企业消息、知识库或其他厂商的回答。
- 先识别唯一输入框，再填入；只有唯一、明确的发送按钮才自动提交。不能识别时保留官网原界面和人工操作路径。
- 对比视图可粘贴/编辑官网回答、复制 Markdown 对比内容、保存为待审核的候选知识。
- 采集只读回答容器，不把整页、侧栏和导航文本当作回答。需要新回答及生成结束的证据，稳定文字本身不等同完成。
- 「采集本轮回答」复用发送前的消息计数基线，适用于登录或手动发送后继续读取结果；它只观察，不会再次填入或发送。旧记录缺少基线时保留粘贴保存。
- 取消停止后续处理，不撤回官网消息；超时、休眠、页面变化和连接中断都不会自动重发。应用重启时在途状态变成「需要核对」。
- 六个厂商最多各保留一个本地 guest。切换主题前检查原页面草稿和生成状态；有未完成操作则保留原页面。

目前只在工作台组件保持挂载期间保留原网页；插件停用、卸载、开发热更新或离开导致整个工作台卸载时，不能承诺未发送官网草稿仍在。正常退出软件也不备份官网草稿。

## 实现模块

| 职责 | 文件 |
| --- | --- |
| 厂商、状态、来源URL与迁移标准化 | `src/shared/web-ai.ts` |

| 原子业务写入、幂等与执行栅栏 | `src/host/application/web-ai-service.ts` |
| 内嵌存储能力协商 | `src/client/features/web-ai/browser-session.ts` |

业务主题、问题和已保存回答存入现有 `state.json` 的 `webAI` 字段，并进入现有迁移包。浏览器 profile、Cookie、凭据、连接信息和在途执行栅栏不进入迁移包。合并超过100个主题或300轮时拒绝导入，不截断已有记录。

## 验证分层

自动化覆盖真实业务服务、原子持久化、批次去重、仅填入不发送、旧答案隔离、取消迟到结果、休眠间隔、未知结束状态、DOM输入、人工保存及页面保留。备用 Chrome 使用临时资料目录启动两次，验证非敏感 localStorage 标记保留；这证明资料目录机制，不等同任何厂商真实登录验收。

实机通过 DeepSeek Harness 正常界面进行。只使用带「网页对比验收20261028」标记的合成草稿，不发送企业内容，不操作官网账号或接受注册协议。

逐站登录、登录后的真实自动发送/回答提取、凭据过期和长期恢复仍需相应官网账号。未登录首页能加载，不代表上述功能通过。结果与未完成项在 `TODO-AI-AUTOMATION.md` 和 `evidence/web-ai-comparison-2026-10-28.json` 分别记录。
