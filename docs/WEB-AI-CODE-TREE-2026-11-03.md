# 多 AI 对话：架构树与多行代码格式

## 原因

只读核对对应 ChatGPT 记录后发现：换行和缩进仍然保存在正文里，但整个目录树被序列化成了单反引号行内代码。Markdown 会将行内代码中的换行折叠为空格，因此本地出现横向拼接与折行，官网仍保持正确目录树。

## 修复

- 网页中的多行 `code` 即使没有 `pre` 包裹，也转换为代码围栏。
- `pre`、CodeMirror 行节点及 `br` 保留换行、空行和缩进；过滤按钮、行号及隐藏辅助内容。
- 依据内容中的反引号长度选择围栏，防止代码正文提前闭合代码块。
- 展示旧记录时，仅恢复单反引号内带明确树形分支的多行目录树，不改写保存的数据，不需要重新提问。
- 已有围栏、缩进代码示例和普通行内代码保持原义。没有保留下来的换行不作猜测恢复。
- 沿用已有等宽代码块样式，长行在块内横向滚动。
