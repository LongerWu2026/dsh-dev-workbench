# 网页 AI 对比适配复验

日期：2026-10-28，Asia/Shanghai。

后续状态：2026-10-29 已解锁并完成本页留下的两项无账号实机复验；千问和 ChatGPT 后台填入均通过，详见[无账号复验记录](WEB-AI-ANONYMOUS-VALIDATION-2026-10-29.md)。下文保留原测试当天的观察，登录后的验证仍未完成。

## 界面与交互

- 取消首次提问前手动创建「对比主题」。首次提交与历史建档在一次原子业务提交中完成，重复请求不会生成空主题。
- 主界面固定展示问题和回答。厂商标签只筛选已有回答，不发送消息。官网默认隐藏，仅在「登录 / 查看原对话」展开。
- 同一家连续追问复用其原会话；新厂商不会收到其他厂商的回答或企业上下文。
- 两家并行、同站串行；未确认官网接收时及时停止等待，不反复点击发送。
- 新增「采集本轮回答」。保存发送前的消息计数，不保存旧回答正文或授权信息；恢复采集只读取页面。

## 修复与规则

- 将六家声明式规则集中到 `src/shared/web-ai-adapters.ts`，与执行器分开。清言输入区及 `.enter-icon-container:not(.empty)`、元宝 `#yuanbao-send-btn` 来自本轮正常界面内的受控 DOM 诊断。
- 不把活动弹窗里的「登录」字样等同于认证失败；有实际认证表单的弹窗才报告需要登录，其他弹窗要求先在官网处理。
- 透明隐藏的登录框、输入框和按钮不参与操作；没有明确发送控件时不猜测点击。
- 等待官网前端输入组件挂载，避免 `dom-ready` 后 React 尚未完成时误报失败。
- 修正长历史超过8条时，相同内容的新回答无法归属的问题；不同新问题出现时停止采集，防止串入他人/手工追加的回答。
- 对千问的 Slate/Lexical 占位提示作语义排除，仍保护真实未发送草稿。
- ChatGPT 后台执行出现一次超时，已调整隐藏网页的承载位置；这项修改还需要解锁后的实机复验，不按通过核销。
