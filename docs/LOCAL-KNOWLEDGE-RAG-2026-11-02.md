# 插件本地 RAG 与知识空间隔离

本版在插件内完成本地向量化，不安装 Python、Ollama，不另开浏览器或 Electron 窗口。默认关键词检索；本地语义增强由用户按需启用。本机原版 Harness 已准备模型并建立当前范围索引。

## 使用

1. 知识空间 → 本地语义检索 → 下载并启用；同一模型只下载一次。
2. 选择知识空间和项目，维护资料；已确认、有效且未归档的正文参与检索。
3. 新增、编辑资料会在已启用且模型就绪时自动增量索引，也可手动“更新当前范围索引”。
4. 助手知识设置默认跟随当前事项，待办、关联回复、研发事项自动继承项目。无工程关联的旧研发记录不误用默认项目。
5. 同一范围复用会话；跨范围不在原会话继续注入资料，保留历史并提示新建对话。知识助手按范围选择独立会话。

## 隔离规则

- 知识空间 → 项目；个人知识、公司/客户空间互相隔离。
- 当前项目可检索该项目资料与同空间公共资料；其他项目不自动纳入。
- 个人通用知识只有明确勾选“允许其他知识空间检索此通用资料”，才可跨空间复用。
- 账号是来源元数据，不再作为主界面检索范围或登录权限声明。来源中的测试账号不会生成空间选项。
- 旧账号专属知识映射为历史来源空间，原账号与正文保留，不自动提升为通用知识。
- 管理知识空间可创建空间、设置项目归属；显式设置项目归属时，项目已有知识随项目移动，来源账号不变。
- 关键词、向量候选、手动知识上下文、原文回读、检索历史、会话及操作确认使用同一范围规则。资料更新/失效后旧引用拒绝回读。
- 当前是个人本地工作台的范围隔离，不是多人服务的身份认证和成员权限系统。

## 本地模型与索引

- BGE-small-zh-v1.5 INT8，固定模型版本 `75c43b069aac4d136ba6bc1122f995fedcfd2781`，512维。
- Transformers.js 3.8.1 自包含浏览器构建 + ONNX WASM，在独立 Node Worker 中执行。
- 8个固定资源，总计 **46,979,851 字节**；模型/分词等资料 **24,451,175 字节**。逐文件检查声明大小和 SHA-256，校验后安装，未校验代码不执行。
- Worker 只访问本地已准备资源，禁止外部模型请求；CPU单线程，每批最多2段，空闲15秒终止Worker。插件停用中止下载和计算。
- 文档分段上限350字符，长单行也分段，引用含行号及片段序号；标题参与向量化时最多80字符。
- 增量向量按模型、文档版本、片段与内容散列保存为 Float32，每片段2048字节。并发读取有界，重启复用，不把向量写入业务 state.json。
- 提问中缺失索引超过8段时回退关键词并排队后台索引，避免在一次提问内等待大规模建库。
- BM25与向量相似度结果用RRF合并，最多8个引用，单文档最多2段，片段正文合计最多10000字符；外部Embedding兼容入口仍保留，本地增强开启时优先本地。

数据位置：

```text
$DSH_HOME/storages/dev-workbench/
  state.json                         # 知识正文、空间与项目归属
  assistant-hub.json                 # 会话与知识范围绑定
  knowledge-engine/config.json      # 启用选择
  knowledge-engine/<模型版本>/
    runtime/                         # 固定WASM运行时
    models/bge-small-zh/              # 固定模型及分词器
    vectors/*.f32                    # 可重建的持久化派生索引
```

便携业务导出包含知识空间、项目归属及知识资料；模型与派生索引不放入业务迁移包，可重新下载/重建。支持旧迁移包缺少 knowledgeSpaces 字段。
