## 4. 已知未实现（界面中不假装可用）

1. 云之家写操作（发消息/撤回/审批/删除）：**刻意不实现**。插件只挂 27 个只读命令的 allowlist，写操作留在会话里走逐次审批 + CLI 的 exit-10 确认闸门（§7.1 L3 分级）。
   已接入：@我 拉取、消息搜索、文档标题搜索（whoami 已验证）。未接入：游标增量同步、联系人/日历/考勤三路、知识文件正文检索。
2. 企业搜索 / 企业知识文件检索：搜索页的「企业（云之家）」一路诚实显示未接入与原因，不返回任何伪造结果。
3. PR / Review / CI 状态、进程 CPU/内存、服务探测：需要平台凭据或扩大本地探测面，未接入（研发协作已含 git 状态、docker ps、监听端口）。
4. AI 摘要与 GitHub Trending：插件内没有模型——抓取条目只保留原文摘录、四段摘要留空，归纳交给会话里的 Agent 并用 workbench_record_run 写回；GitHub Trending 无稳定 RSS，不猜测第三方地址。
5. SQLite 存储：刻意保留原子写入单文件 JSON（schema 版本与幂等约束已具备）。当前状态是单文档内存模型，多表 SQLite 不改变模型只增加复杂度；如需迁移，`version` 字段已预留。
6. 定时抓取：不自带调度器。替代闭环 = DSH Schedule 每日提醒（原生能力）→ Agent 调 `workbench_fetch_radar` → 抓取报告落库 → 首页陈旧标记。
7. L3 高风险操作（发消息、推代码、写数据库）——插件根本不具备这些能力。

## 13. 搜索联动补全（2026-10-28）

- 搜索页默认**不联网**（只搜本地与已有来源），「含互联网」变为显式开关，符合「离线搜指定内容」。
- 命令面板选中具体结果 → `searchPreset.groups` 会**映射到对应分类**（待办→本地、日程→企业、

## 14. 会话标题杂料修复（2026-10-28）

- 症状：助手侧栏会话下拉显示「★ 添加时区（需要落库时请直接调用…」——标题取自会话首条
  user 消息，而那是我们组装的 prompt（含「【工作台上下文】」头与尾部指令）。
- 处理：新增 `stripAssistantBoilerplate`，在**会话标题 / 历史回显 / 增量条目 / 会话记录**四处

- 证据：host-smoke 场景 1b（标题不含「工作台上下文/需要落库时」，记录只显示真实内容），186/186。

## 14. 搜索收敛完成（2026-10-28）

- **改名**：「统一搜索」→「搜索」，明确它是唯一搜索入口。
- **一个入口**：⌘K 命令面板内可直接本地检索（不联网），结果按来源分组内联显示，
  回车进「搜索」页看全部——不再需要在两处重复输入。
- **预设交接**：命令面板选中某条结果 → `searchPreset` 带查询词进搜索页自动执行。
- **分类筛选**：搜索页新增分类行（全部 / 本地 / 企业 / 代码 / 互联网），
  与原有逐路开关叠加；每类列出包含的路（hover 可见）。

## 14. 助手中途「白块」修复（2026-10-28）

- 症状：流式回答过程里，消息流中段出现来路不明、样式不对的色块；最终回复本身正常。
- 根因：每轮的工具事件（tool / toolResult / error）逐条原样渲染——工具名 + JSON 参数摘要
  挤在一行里，没有气泡边界，视觉上就是孤立的白块。
- 处理：连续的工具事件**折叠成一条**「调用了 N 个工具」行（虚线框 + 命令图标 + 工具名列表），
  原始参数收进 hover 提示；含失败时标注（含失败）。错误行仍单独可辨。

## 14. 搜索收敛与 Agent 中心计数（2026-10-28）

- **顶栏搜索按钮移除**：内容目录本身不多，搜索完直接跳转价值低；「搜索」页作为唯一搜索入口，
  ⌘K 仍可呼出命令面板（纯键盘操作）。
- **仓库删除前的误报修复**：研发协作卡片按归一化路径 + 项目名匹配项目；
  只有匹配到项目记录才显示删除按钮，Host 工作目录条目改为「工作目录」提示，不再弹「找不到对应项目」。
- **Agent 中心「执行中」计数修正**：`queued`（排队中）此前不计入任何卡片，
  现在「执行中」= queued + running，副标题展示明细（「N 排队 · M 执行」），点击卡片切到「活跃」筛选；
  侧栏「Agent 中心」条目在有活跃执行时显示数量角标。

## 14. 助手界面纯化（2026-10-28）

## 17. 生效条件

- 只改 `src/client/**`：重新构建后刷新 GUI 窗口即可。
- 改 `src/host/**`（新增 Remote 端点或工具）：必须**重启 DSH**；重新安装 bundle 不会替换已加载的
  JavaScript 模块代际。
