# 消息卡片标记与底部间距

普通问答原来的“已回复”表示模型轮次结束，容易与云之家待回复的业务状态混淆；成功的纯 AI 回答现在只保留 AI 来源标记。

- 生成中、失败、中断、需确认、待补充及没有最终正文等状态仍显示。规则操作、真实业务执行、后台作业及历史结果的状态保留。
- 底部标记统一 16px 行高，缩小卡片底部内边距和元素间距；不渲染空的成果容器。
- 紧凑知识引用去掉额外上下外边距，保留引用、展开及原文读取能力。其他非紧凑知识面板不受影响。
- 会话、草稿、附件和历史阅读逻辑保留。界面回归发现发送请求尚未返回时跳过详情读取，会漏掉后台已接收附件的确认；现仅对仍等待附件接收回执的临时轮次保留详情读取，不恢复已接收的正文或附件。

- `node plugin-tests/layout/assistant-tool-activity.mjs`：18 组通过；360/640/1280px、明暗主题、普通及专用会话。普通问答标记仅 AI、行高 16px、知识引用至标记间距 8px、知识引用下方总高度 33–35px，草稿与输入节点保持。
- 原版 Harness：打开用户“查询当前目录技能数量”中的原回答，已核对 AI 标记单独显示、“已回复”消失，知识引用和正文保留、底部留白收紧。未重新发送消息。
