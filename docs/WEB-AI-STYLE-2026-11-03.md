# 多 AI 对话与 AI 助手风格统一

本次修改页面布局与共享组件，不改变官网发送、登录、回答采集和历史管理的数据协议。

- 复用 `AssistantSidebar`、折叠按钮和尺寸观察逻辑，桌面侧栏统一200px，折叠为40px窄栏；窄面板使用抽屉，支持遮罩、Escape、焦点限制与返回。
- 会话项统一背景、选中态、字体与10px/8px内边距；标题最多两行，完整标题保留tooltip。新对话提示与历史条目均不参与高度拉伸。
- 标题、搜索与历史管理固定，只有历史列表滚动；显示最近更新和问答轮数，搜索结果附命中摘要，保留20条分页加载。
- 复用 `MessageRow` 与消息身份样式，我方消息居右、厂商回答居左，保留各轮厂商切换和流式文本原节点。
- 框架、圆角、边界色、正文及输入框宽度/边距与AI助手一致；窄屏12px正文边距、桌面24px；发送与附件按钮统一使用现有图标。
- 清理多套互相覆盖的聊天CSS，保留官网登录浮层、状态及历史编辑样式；矮窗口的厂商菜单限制高度并滚动，不被聊天区域裁切。
- 折叠不卸载聊天与输入区域，保留当前会话、正文草稿、附件和厂商选择。滚动阅读不因新回答追加而自动跳到底。
