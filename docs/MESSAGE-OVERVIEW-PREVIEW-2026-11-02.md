# 消息概览与未读会话预览

消息概览移除常驻的查阅规则及AI过滤解释段落，保留未读数、@本人/@全员累计收录、快照/日历状态，以及待回复、待处理与会议入口。

## 展示行为

- 概览默认打开，未读会话直接显示前3条，不再要求先展开内部列表。
- “展开更多”每次追加3条，末批按实际剩余数量展示，并显示已展示/总数；“收起列表”恢复3条。
- 原有AI无关会话过滤继续生效，查看入口简化为“显示已收起 N / 隐藏已收起”。展开更多不会自动放开过滤。
- 会话名称最多显示两行；完整名称保留在按钮的可访问名称与悬停提示中，点击仍进入原会话阅读器。
- 同账号快照刷新保持已展开数量；切换账号恢复3条并清理上一个账号的临时选择。手动折叠整个概览后，普通刷新不会强制重新打开。
- 上述按钮只更新本地视图，不采集新消息、不调用AI、不修改云之家未读标记或工作台的待办/待回复。已有会话查阅与状态同步规则不变。
