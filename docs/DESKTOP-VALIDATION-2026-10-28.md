# DeepSeek Harness 桌面验收记录

日期：2026-10-28，Asia/Shanghai。目标为本机 DeepSeek Harness 0.2.1-rc.3、desktop profile、本地链接的工作台 0.2.0 工作树。使用原生软件操作验证，未运行 Playwright/CDP 脚本。

结论：主要办公闭环已在真实桌面及软件已有 GLM-5.3-Flash 模型下跑通。早期软件控制拒绝和独立 headless 默认路由缺少凭据的记录已被后续实机结果取代；没有新建供应商配置、读取或复制 API Key。

## 数据边界

开始前将原状态保存到本机临时验收目录。原 schema v1、revision 53，已有 80 条来源、80 条识别队列、15 条资讯；原待办和 Reply 均为空。升级保留原记录。

语义验收使用 `aw-src-* / aw-entry-*` 十条本地合成消息，通过 GUI 预检与合并加入；没有向企业联系人发送测试消息。每条识别均限定对应 ID，原队列未被这组语义验收顺带处理。随后单独开启一次实际后台流程，以该轮结果核验真实采集和调度。普通迁移包不含凭据或原生会话。

## 本轮发现并修复的问题

1. 助手把首个空增量误作结束：改为等待明确 turn/end；会话切换后的旧回包用请求代数丢弃，完整会话入口注入官方 workspace 服务。
2. 消息分析把“需要回复”误等同业务处理，且多事项 Reply 只链接首项：校准提示、字段验证与合并关联。
3. 本人实质答复仅匹配 Task 时漏掉 Reply：明确引用活跃 Reply 必须输出沟通阶段，兼容阶段名称，缺失时显式失败。
4. 单条识别只支持批次、完成记录不能重放：增加 onlyIds 和完成历史入口，避免反复处理无关队列。
5. 资讯页展开、编辑操作未接线，菜单被卡片裁切，未知日期冒充日期：接线并补真实交互回归。
6. 资讯正文导航噪声、末尾可用性限制丢失：保留正文首尾和限制窗口；明确历史日期 URL 只作旧文排除。
7. AI Agent/RAG 查询歧义、总只处理前三主题：限定语义并轮换所有关注主题。
8. 编辑标题意外拆分含空格标签、截断截止时间秒数：未改字段保留原值；工具支持 tags，人工标签纳入保护。
9. 原生更多菜单未自动收起、页内会议时间不可见：补外部点击关闭、筛选重置及会议开始展示。
10. 底部主要操作被外部挂件遮挡：编辑保存和助手发送移到左侧；窄窗口单页显示编辑/助手，草稿可恢复。
11. 助手显示“打断”但执行中不能提交：允许带 steer 的新请求，旧轮次不覆盖新轮次。
12. 自动化立即执行没有等待反馈且吞掉错误：锁定按钮、显示执行状态和失败信息，完成后同步结果。
13. 云之家 token 到期说明显示 UTC 时间但未标时区：明确显示 UTC+8。
14. 首次补采的旧交办直接生成当前义务：默认14天以外先复核；不自动创建历史Task/Reply，不消耗模型逐条处理旧队列，可逐条识别并确认。此前产生的三条旧Task已通过工具改为待审批并加“历史补采待复核”标签，保留原内容。
15. 云之家10000429后继续请求其他会话：立即冷却两分钟，持久化未读取会话，恢复后继续；真实运行与隔离冷却/恢复回归均有证据。
16. 待审批被算入执行中：统一统计只将running计为执行中。
17. 历史消息全部挤占待确认：未识别历史记录单列“历史暂存（按需复核）”，不计为当前待确认；只有主动识别后确有义务才等待建档确认。
18. 退出中断的批次要等待旧租约到期：单Host新进程立即恢复为pending；独立进程验证未来租约也能恢复，任务数量不变。

## 界面走查

十个页面均在实际软件打开：今日、任务、待回复、资讯、知识、搜索、Agent、开发工具、研发、设置。顶部五项和更多入口可达。

已检查普通 1280×820、全屏 1920×1080、系统半屏窗口；宿主侧栏展开/收起；明暗主题，结束后恢复跟随系统。窄工作区（≤1024px）使用单页上下文模式，关闭即可回到原页面。任务编辑时切换知识页，再继续编辑，草稿仍在。
