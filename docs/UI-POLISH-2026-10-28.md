# 顶部导航与聊天菜单样式修复

2026-10-28。本轮按用户两张截图修复界面，同时核对剩余事项；没有修改宿主模型配置或主动写入业务记录，后台正常识别继续运行。

## 修复结果

| 位置 | 原因 | 修改 |
| --- | --- | --- |
| 顶部目录 | 顶部按钮仍继承旧侧栏的`inset`选中竖线，又叠加底部横线 | 移除两种线，统一36px高的圆角选中态、图标和间距；更多目录选中后保留名称和状态 |
| 更多目录 | 原生details标记与手写箭头、菜单样式各自处理 | 使用现有SVG箭头，统一轻边框/圆角/行高；窄容器下更多入口靠右，避免换行后菜单向左溢出 |
| 聊天回复操作 | 用`currentColor`作为边框，浅色下成为黑边；字号11px、图标11px，点击区域小 | 独立作用域样式，13px文字、15px图标、36px菜单项；轻边框、适量阴影及可见悬停/焦点；脱离工作台页面也可正常显示 |
| 菜单交互 | 缺少完整键盘及关闭行为，旧向上箭头名称不存在 | 使用现有箭头旋转；支持方向键、Home/End、Escape、Tab及点外关闭；异步操作禁重入，失败可重试，完成时保留外部编辑焦点 |
| 失败提示 | 已失败3次却显示“重试第4次” | 改为“已失败3次 · 需手动重试”，与实际attempts一致 |

聊天样式节点随插件注册创建和清理，旧实例仅清理自身节点。没有把整套工作台样式注入原生聊天，也没有改变三个操作的业务RPC。

`pnpm build`、`pnpm check`、`pnpm test`、`git diff --check`均返回0：Host235、可靠性56、React30（5个文件）、十页首屏渲染通过。

新增5个React行为验证：原生聊天单独装载样式；正确Session/Message ID及忙碌锁定；方向键/Escape/点外关闭；读取失败与重试；异步完成不夺走其他草稿焦点；另有更多目录选中及Escape返回焦点。前两项在一个用例内覆盖。

实机通过：浅色/深色顶部导航与更多菜单、聊天菜单展开、再次点击关闭、Escape关闭并返回触发器。临时切换深色后已恢复原“跟随系统”。窗口输入曾遇到旧绑定，重新绑定后Escape验证成功。原生拖拽收窄工具返回`noWindowsAvailable`，没有把窄窗口矩阵列为本轮实机通过，完整显示矩阵仍归18。
