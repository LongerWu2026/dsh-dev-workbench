# 待办独立会话与聊天导航

不同待办的 AI 协助按待办 ID 绑定原生 Harness 会话，同一待办再次点击恢复最近使用的会话。每条待办可以新建多段会话，选回该待办的历史会话后，下次仍恢复所选会话。关联保存在本机 assistant-task-threads.json（0600），不混入可迁移的业务数据包，不删除原生会话日志。

历史列表同时展示其他待办和通用办公会话。切换到另一条待办的历史时，自动切换所属待办并替换引用；原来的通用办公历史保留供手动选择，不根据相似标题自动归属到某条待办。后台校验会话归属，拒绝跨待办读取、发送和打断；原有研发、审查及 Linky CLI 会话隔离继续生效。

界面由长下拉改成左侧可搜索会话列表、右侧对话与输入区，列表可折叠，窄屏自动折叠。当前待办与会话显示在顶部。草稿在本次运行中按会话分别保留。切换后旧轮次与旧历史请求的晚到回包不能覆盖新会话；恢复或创建期间输入、发送锁定，避免误发到上一个会话。打开和切换本身不发送模型请求。

冷会话通过宿主 resolveAgent 恢复；服务不可用或非确定性存储错误不静默替换原记录。同一待办首次并发打开复用同一创建任务。明确的原日志丢失可创建替代会话，同时保留旧历史索引；模型配置的 not found 错误不会冒充日志丢失；模型提交时恢复日志的兼容逻辑也保持待办归属。
