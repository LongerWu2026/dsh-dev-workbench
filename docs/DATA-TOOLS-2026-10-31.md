# 轻量数据连接工具

入口：开发工具箱 → 数据连接。直接调用驱动，不引入连接器框架或完整数据库客户端。

查询区右上角提供“AI 生成”：勾选对象后描述需求，点击“生成并填入”，结果直接放入查询编辑器；可复制 SQL，也可检查后点击执行。已有 SQL 可直接粘贴到编辑器查询，无须先打开 AI。

## 当前能力

- MySQL/mysql2 与 PostgreSQL/pg：填写数据库名称、测试连接、列出表、读取所选结构、执行单条 SELECT/WITH 查询。PostgreSQL包含字段类型/注释、约束与索引；MySQL读取建表定义。返回上限200行、1MB，精确数值尽量保持字符串。
- Elasticsearch：Basic认证或无认证，读取索引、Mapping，执行单索引搜索DSL。固定搜索超时15秒，结果size最多200，响应上限1MB。超时部分结果明确提示。
- Redis/ioredis：单节点、指定DB、SCAN分页、查看Key类型和TTL。支持受限的字符串/列表/集合读取命令；不支持写入、脚本执行或集群拓扑管理。
- AI：勾选1至12个对象，描述要求。生成前实时刷新结构，传递数据库类型及所选元数据，不传密码、连接地址或业务行数据。独立宿主模型会话返回查询/解释；SQL变更脚本及回滚建议仅预览。执行生成查询时重新核对结构指纹，变化则拒绝执行旧查询。
- 查询必须由用户点击执行。SQL使用语法树检查与数据库只读事务，不开放写入入口；仍建议使用只读数据库账号，客户端检查不替代数据库权限。

## 连接生命周期与存储

非密码配置保存在DSH_HOME/storages/dev-workbench/data-connections.json，固定路径，不接受外部文件路径。密码仅在宿主内存，重启或断开后需重新填写并保存解锁；保存时留空可沿用当前内存密码。

按需建立单连接，每个配置串行操作，全局最多4个数据操作。连接超时10秒，数据操作35秒，空闲120秒关闭网络连接。断开与插件释放关闭资源。失败不重发查询。取消本地等待不承诺服务端操作一定结束。

SQL/Redis可启用TLS并填写PEM格式CA；不静默关闭证书校验。ES使用系统HTTPS验证，暂不支持自定义CA、API Key、SSH隧道。首版不提供连接删除、结构编辑、数据修改、导入迁移、备份或事务脚本执行。

## 体积

驱动为生产依赖；node-sql-parser仅为开发依赖，构建时只嵌入MySQL/PostgreSQL语法及big-integer，避免把约88MB完整解析库作为生产依赖安装。附THIRD-PARTY-NOTICES.txt。前端不打包数据库驱动。

- tests/data-postgres-real.mjs：临时安装embedded-postgres并启动只监听127.0.0.1的真实PostgreSQL。验证连接、注释/约束、精确数值、空列结果、200行限制、只读事务阻止写函数、结构变化拒绝旧查询及断开。测试结束停止临时实例。
