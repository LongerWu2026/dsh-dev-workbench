# 轻量数据连接工具

入口：开发工具箱 → 数据连接。直接调用驱动，不引入连接器框架或完整数据库客户端。

查询区右侧提供“AI 会话”：勾选对象后描述需求，生成结果保留在会话中；只有点击“填入 SQL 编辑器”才回填，检查后由用户执行。已有 SQL 可直接粘贴到编辑器查询，无须先打开 AI。结果视口固定为360px，超宽或超高内容在内部滚动。

## 当前能力

- MySQL/mysql2 与 PostgreSQL/pg：填写数据库名称、测试连接、列出表、读取所选结构、执行单条 SELECT/WITH 查询。PostgreSQL包含字段类型/注释、约束与索引；MySQL读取建表定义。每页可选50/100/200行，翻页继续读取原查询结果；保留原SQL的排序、LIMIT/OFFSET与集合语义，不自动统计总数。每页行数据上限1MB，精确数值尽量保持字符串。行数探测、字节截断与单元格截断分别提示；深分页可能较慢，跨页读取不是一致性快照。
- Elasticsearch：Basic认证或无认证，读取索引、Mapping，执行单索引搜索DSL。固定搜索超时15秒，结果size最多200，响应上限1MB。超时部分结果明确提示。
- Redis/ioredis：单节点、指定DB、SCAN分页、查看Key类型和TTL。支持受限的字符串/列表/集合读取命令；不支持写入、脚本执行或集群拓扑管理。
- AI：勾选1至12个对象，描述要求。生成前实时刷新结构，传递数据库类型及所选元数据，不传密码、连接地址或业务行数据。独立宿主模型会话返回查询/解释；SQL变更脚本及回滚建议仅预览。执行生成查询时重新核对结构指纹，变化则拒绝执行旧查询。
- 查询必须由用户点击执行。SQL使用语法树检查与数据库只读事务，不开放写入入口；仍建议使用只读数据库账号，客户端检查不替代数据库权限。

## 连接生命周期与存储

连接配置保存在DSH_HOME/storages/dev-workbench/data-connections.json，固定路径，不接受外部文件路径。密码默认只保存在宿主内存。macOS 上可勾选「记住密码」，工作台将密码加密，密钥由系统钥匙串保管。重启后首次使用连接时自动恢复密码。取消勾选并保存可清除密码密文。

每个连接目标的工作区独立保存在同目录的data-workspaces.json，按数据库类型、地址、端口、库名、账号和TLS安全上下文识别。保存最近20轮AI对话、未发送需求、SQL、对象选择、分页设置和最近一页结果；改名、重复添加同一目标或轮换密码不会清空，改库/账号/安全上下文使用独立记录。文件为0600私有权限但不加密，最多30个目标、每个目标4MiB，不进入通用工作台快照或便携导出。可点击“清除当前连接记忆”显式删除。恢复结果带“上次查询结果”时间标识，不自动重新执行SQL；密码和密码密文不写入工作区文件。

按需建立单连接，每个配置串行操作，全局最多4个数据操作。连接超时10秒，数据操作35秒，空闲120秒关闭网络连接。断开与插件释放关闭资源。失败不重发查询。取消本地等待不承诺服务端操作一定结束。

SQL/Redis可启用TLS并填写PEM格式CA；不静默关闭证书校验。ES使用系统HTTPS验证，暂不支持自定义CA、API Key、SSH隧道。首版不提供连接删除、结构编辑、数据修改、导入迁移、备份或事务脚本执行。

## 体积

驱动为生产依赖；node-sql-parser仅为开发依赖，构建时只嵌入MySQL/PostgreSQL语法及big-integer，避免把约88MB完整解析库作为生产依赖安装。附THIRD-PARTY-NOTICES.txt。前端不打包数据库驱动。
